# Remotion template — layout, customization, commands

The template lives in `assets/remotion-template/`. Copy it into the user's project
(e.g. `<repo>/reel/`) and customize the marked files. It composites: full-frame B-roll →
split-screen beats → grain/vignette → captions → audio.

## File conventions (paths are under `public/`, served by Remotion)

```
public/source/speaker.mp4   # downscaled, MUTED talking-head (opener + split top pane)
public/audio.m4a            # spoken audio = the reel's soundtrack
public/broll/clipN.mp4      # generated B-roll clips
public/fonts/brand-*.ttf    # brand fonts (medium/semibold/bold/extrabold)
out/audio16k.wav            # 16k mono wav for caption alignment
src/captions.json           # generated by scripts/align_words.py
```

`scripts/prep_source.sh <source_video> [W] [H]` produces the first three from a raw source
(downscales, strips audio for the video copy, extracts audio + the 16k wav). Downscale 4K
sources — the split pane only needs the composition height and it renders much faster.

## What to customize (the only files that change per project)

- **`src/config.ts`** — `SOURCE_VIDEO`, `AUDIO` paths (usually leave as defaults).
- **`src/brand.ts`** — `BRAND.bg / text / accent` colors + `FONT` family. From onboarding.
- **`src/fonts.ts`** — map the brand `.ttf` weights copied into `public/fonts/`.
- **`src/shots.ts`** — the shot list: `SHOTS[]` (timing windows, `mode`, `push`, `file`,
  `prompt`) plus `WIDTH`/`HEIGHT` (aspect ratio) and `TOTAL_SECONDS` (= audio length).
  Windows MUST be contiguous and end at the audio duration.

Components (`BrollTrack`, `SplitOverlay`, `Captions`, `GrainOverlay`, `Reel`) rarely need
edits — they read the config/shots/brand.

## How the pieces work

- **BrollTrack** renders only `mode: "full"` shots, full-frame, with `XFADE` crossfades and
  a slow Ken Burns `push`. Split shots are skipped here (SplitOverlay draws them).
- **SplitOverlay** renders `mode: "split"` shots: speaker on the top half, that shot's clip
  on the bottom half — **both centered crops** (`objectFit: cover` + `objectPosition: center`)
  so subjects sit centered with an equal top/bottom cut. Tune the speaker's vertical framing
  with the second value of its `objectPosition` (e.g. `center 50%`). An accent hairline
  divides the panes.
- **Captions** shows the active phrase from `captions.json`, active word accented. See
  `references/captions.md` for styles (phrase vs one-word, case).
- **GrainOverlay** is the unifier — animated film grain + vignette that ties clips from
  different prompts (and the real footage) into one look. Do NOT skip it; it hides the
  720p upscale and seams.

## Gotchas

- **Font loading** happens inside the `Reel` component (`loadBrandFonts()` at the top of the
  component), NOT at module top level — a top-level `delayRender()` fires during Remotion's
  composition-listing phase and throws on a full render.
- **Clip length ≥ its window** (+~0.5s crossfade lead). The editor trims; it won't invent
  frames. If a clip is too short you get a freeze.
- **Everything referenced must be under `public/`** — `staticFile("source/speaker.mp4")`
  resolves to `public/source/speaker.mp4`.

## Commands

```bash
cd reel
npm install
scripts/prep_source.sh /path/to/source.mp4        # -> public/source, public/audio, out/audio16k.wav
pip install faster-whisper                          # once
npm run captions                                    # align words -> src/captions.json
# ... drop generated clips into public/broll/ ...
npm run studio                                       # live preview + tweak at localhost:3000
npm run render                                       # -> out/reel.mp4
```

Validate fast with a still before a full render:
`npx remotion still src/index.ts Reel out/chk.png --frame=240`.
